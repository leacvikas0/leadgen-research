# Hunter workflow — Photographer portfolio (Task 0)

Canonical copy of the quality finder pipeline.  
Synced intent with `../hunter-workflow.md` (root); **prefer this docs path** going forward.

---

## Principle

```
Discovery → Hard qualify (N×A×T) → Enrich → Pitch asset → Human approach → Log
```

No asset + no score → no message.

---

## Stage 0 — Lock corridor

- City / belt  
- Vertical: wedding photographer only (v1)  
- Target: 15–25 gold per batch, 8–12 sends  
- Proof: Clara + Karamjot  

---

## Stage 1 — Discover (quality density order)

1. **Instagram** — city tags, hashtags, venue tags, collab graph from seed shooters  
2. **WedMeGood / vendor lists** — then verify owned web presence  
3. **Google** — `wedding photographer [city]` + Maps pack → open IG/site  
4. Venue reels / tags  
5. FB groups hand-raises (low volume)  
6. Maps empty website alone — **never auto-qualify**

---

## Stage 2 — Score (0–2 each; park if any = 0)

**NEED:** no site / Linktree / Drive / weak old vs strong portfolio  
**ABILITY:** real weddings, venues, packages vibe vs hobby  
**TIMING:** active, season, rebrand, ads vs dead account  

**Gold:** all ≥1, total ≥4, hard signal = real wedding volume + no real portfolio home  

---

## Stage 3 — Enrich fields

```
name, ig_url, city, whatsapp_or_phone,
website_status (none|linktree|weak|good),
need_note, ability_note, timing_note,
score_n, score_a, score_t, score_total,
proof_hook, status, source, date_added, outcome
```

---

## Stage 4 — Pitch asset

One of: gap screenshot | their work on our layout mock | peer proof links | city competitor FOMO  

---

## Stage 5 — Approach

AI drafts → **human** WA or IG send → reply assist later  

---

## Weekly loop

Mon discover → Tue score → Wed assets → Thu send → Fri follow-up → Sun source review  

---

## Anti-patterns

Maps-only quality, followers-only, no observation, multi-vertical soup, bulk WA bots, promising story site at portfolio price
