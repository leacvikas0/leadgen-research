## One-line thesis

**Don’t find businesses without websites. Find businesses already paying a platform tax or growth tax, then open with proof + money math — human WhatsApp, not bulk automation.**

## Where demand is real (ranked)

| Rank | Vertical | Why real | Kill if… |
|------|----------|----------|----------|
| 1 | Resorts / homestays / boutique stays | OTA ~12–20% commission = pure margin leak | Hobby 1-room host, zero marketing capacity |
| 2 | Wedding vendors (photo, MUA, decor, venues) | Listings ₹50–85k burned for shared leads | Hobby / ultra-low package only |
| 3 | IG/WA D2C past micro-scale | Ads + DM chaos + trust/COD need owned store | <50–100 orders/mo side hustle |
| 4 | Coaching / multi-batch institutes | Parents Google; ads need LPs; season spikes | Solo home tutor |
| 5 | Specialty clinics / multi-doctor | Trust + appointment URL; GBP still primary | Solo GP full on Practo+GBP |
| 6 | RE channel partners already on portals/ads | Shared portal leads expensive; need exclusive LPs | Random broker walk-in only |
| — | Restaurants delivery-heavy | Commission pain real | **Website rarely the fix** |
| — | AC / plumber / basic salon | High no-site density | **Weak pay + WA/Maps wins** |

**Implication:** Outbound on deep-benefit verticals > waiting for public “need website” RFPs (those are thin).

## Quality filter (not Maps empty field)

```
Score: NEED × ABILITY × TIMING  (then REACH)
Zero on any axis → park, not pitch
```

### Best signals (use these)

1. **Ads running → weak/no/Linktree landing** (N+A+T) — leaking ROAS  
2. **Review text:** can’t book / no hours online / site terrible (N + pitch fuel)  
3. **IG/WA real commerce + no owned domain** (N+A)  
4. **Expansion / admissions season / new property** (T+A)  
5. **Active GBP + owner replies + solid review volume** (A + will answer)

### Gold recipes (hunt these)

| Recipe | Formula | Pitch wedge |
|--------|---------|-------------|
| Ads broken door | Spending + bad front door | “Clicks land here — leak in 3 screenshots” |
| Busy + friction | 20+ reviews + booking/findability complaints | Quote customer pattern, not invent pain |
| IG rented land | Real product velocity + DM/Linktree only | Owned store + WA recovery, not “look professional” |
| OTA margin | Strong OTA listing + no/weak direct book | Commission ₹ math + guest data |
| Admissions machine | Multi-batch + ads/brand + weak course LPs | Season deadline + results/forms |

### Disqualify fast

- Only signal = empty Maps websiteUri  
- 0 reviews + no ads + dead IG  
- “Cheapest website” language  
- Service-quality collapse in reviews  
- Proud offline / referrals-only  
- Stale 2019 site + owner made peace (no timing)

### Better sources than blind Maps

1. Review text friction  
2. Ad → landing audit  
3. IG/WA commerce footprint  
4. OTA profiles  
5. Hiring / expansion posts  
6. Hand-raise groups (low volume, high intent)  
Maps empty field = **CSV residue only**, never “qualified.”

## Selling that converts

```
QUALITY LEAD → SPECIFIC PROOF → ₹ ANGLE → LOW-RISK OFFER → HUMAN FOLLOW-UP
```

### Top offers
1. Fixed “site in Y days” + WhatsApp CTA + GBP link (~₹15–40k band market-normal for real 5-pagers)  
2. Hotel/homestay direct-booking + OTA math  
3. Free *specific* audit → paid fix (not Lighthouse spam PDF)

### Top angles
1. OTA commission save (hospitality)  
2. Google/Maps trust + lost enquiries  
3. Stop DM chaos / IG is rented (with *their* mock)

### Channel sequence
```
Referral/warm → personalized WA or researched call → walk-in + mock (high ticket)
→ close on WA invoice + advance → ask 2 referrals
```
**Not:** cold bulk WA, corporate decks, “AI site in 5 min,” SaaS email sequences as if they were local SMB.

### Message rules
- One specific observation (their name, OTA, review pattern, speed score)  
- Human identity (you + city)  
- One ask (screenshot / 30-sec look)  
- Hinglish OK for most local owners  
- Outcome + ₹, not features

## Hunter agent redesign (from this research)

**Old:** scrape Maps for empty website  
**New:** score composites in priority verticals

```
1. Pick vertical + city corridor (e.g. Goa homestays, Jaipur wedding photo, Kota coaching)
2. Discover via: OTA lists / IG commerce / Maps reviews / Ad Library / FB hand-raises
3. Score N×A×T (gate ≥1 each)
4. Attach pitch asset: OTA calc OR review quote OR ad-landing screenshot OR mock
5. Queue for human approach (draft by AI, send by human)
```
