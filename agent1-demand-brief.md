# Agent 1 brief: DEMAND & DEEP BENEFITS (not vibes)

## Your job
Research **where people actually need a website** — either:
A) **Active hunting** (they ask for designers, RFPs, "need website", "looking for web developer", freelancer posts, community asks), OR
B) **Deep real benefits** (measurable economic reasons a site pays off even if they aren't searching) — not generic "credibility" fluff.

## Geography / market
**Primary: India** (local SMBs, D2C, hospitality, education, clinics, trades).
**Secondary:** transferable global patterns if India-specific data is thin — label region clearly.

## Verticals to pressure-test (rank, kill, or promote with evidence)
1. Instagram/WhatsApp-first ecom / D2C (catalog in DMs, no/weak store)
2. Tuition / coaching / test prep (Maps + IG, no site or broken site)
3. Resorts / homestays / B&Bs (OTA heavy: Booking.com / MakeMyTrip / Airbnb commissions)
4. Clinics / dentists / diagnostic labs
5. Restaurants / cafes / cloud kitchens
6. Real estate agents / builders (local)
7. Wedding vendors / photographers / event planners
8. Local services (AC repair, interior, gyms, salons)
9. Any OTHER vertical with stronger evidence — add it

## What "deep benefit" means (require something like this)
- Revenue: more bookings, higher AOV, fewer abandoned DMs
- Margin: escape OTA commission (cite typical % if found)
- Trust/conversion: review→site→call/WhatsApp funnel
- SEO/Maps: site helps local rank or ad landing
- Ops: reduce phone tag, standardized pricing, brochure replacement
- Seasonality: monsoon tourism, exam season, wedding season, festival ecom

Kill soft claims like "every business needs a website" without a mechanism.

## Methods
- web_search + open primary pages (not just SERP)
- Reddit/forums/India agency blogs for lived demand
- OTA commission data (official or reputable)
- "looking for web designer India" / Justdial / IndiaMART / Quora / Reddit r/india / r/developersIndia / freelance threads if relevant
- Prefer 2023–2026; date claims
